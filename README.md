Steel Corridor is a round-based tactical FPS built with three.js: four tiered bots with line-of-sight, cover-seeking AI, buy phases, an economy, a plantable bomb, and deterministic seeded matches.

## Run it

```sh
npm install && npm run build && npm run serve
```
